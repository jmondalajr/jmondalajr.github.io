Personal Agent privacy policy

Personal Agent is used by one person, its owner, with the owner's own Google account.

The app accesses the owner's Gmail and Google Calendar data to summarise email, list calendar events and send unsubscribe requests the owner selects. This data is processed on the owner's own computer and server. Message content is sent to Anthropic's Claude API to generate responses. It is not sold, shared with any other party, or used for advertising.

The app stores a Google sign-in token on the owner's own machines. Access can be revoked at any time from the Google Account security settings.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
